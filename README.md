# VLSI Foundations

**Building my VLSI engineering foundation, one digital circuit at a time.**

This repository documents my learning journey in digital electronics, Verilog HDL, RTL design, and hardware implementation. It contains my practice codes, testbenches, simulation results, and explanations as I build a strong foundation in digital design and VLSI engineering.

## 🎯 Objectives

- Understand the fundamentals of digital logic design.
- Learn and practice Verilog HDL through hands-on coding.
- Design and simulate combinational and sequential circuits.
- Develop testbenches to verify the functionality of digital designs.
- Analyze simulation waveforms and understand circuit behavior.
- Gradually progress toward RTL design, synthesis, and FPGA implementation.

## 📚 Topics Covered

- Digital Logic Fundamentals
- Number Systems and Boolean Algebra
- Combinational Logic Circuits
- Sequential Logic Circuits
- Verilog HDL Fundamentals
- Testbench Development and Simulation
- Finite State Machines (FSMs)
- RTL Design and Synthesis
- FPGA Implementation

*Topics will be added progressively as I learn and implement them.*


## 🛠️ Tools and Technologies

- **HDL:** Verilog
- **Design and Simulation:** Vivado
- **Hardware Platform:** FPGA development boards
- **Version Control:** Git and GitHub

## 📖 Learning Approach

Each topic aims to include:

- Conceptual explanations and design logic
- Verilog HDL source code
- Testbench code
- Simulation waveforms and results
- Observations and key takeaways

The goal is not just to write code, but to understand the hardware being described and verify its behavior.

## 🌱 Progress

This repository is a work in progress. I will continuously add new concepts, implementations, and experiments as I develop my skills in digital design and VLSI engineering.
